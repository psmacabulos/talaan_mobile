# The UI design

The owner's design for the app goes in this folder: screen images, an exported prototype, a link to a Figma file, or notes. Claude reads it before building any screen (`docs/DESIGN.md`, "The owner's design comes first").

A short index here helps: one line per file or link, saying which screen it shows. For example:

| File or link | Screen |
|---|---|
| `BantayAral Parent App UI Mockup.png` | All ten screens, light only (the first mockup; `docs/DESIGN-QUESTIONS.md` lists where it and the server disagree) |
| `BantayAral Children Dashboard Comparison.png` | Home, light and dark: the header, the child card, the tab bar (2026-10-27). Its "Your children" is now "My children", and the tab is "Home" |
| `BantayAral UI Brand Asset Sheet.png` | Logos, app icons, tab, status and UI icons, illustrations, background shapes, as one picture (2026-10-27). The file names on it are labels: the separate files aren't in this folder |
| `logo/` | The logo as separate files (2026-10-28): SVG and PNG mark, light, dark and one-colour, the full logo with its name, and ready-made app icon, splash and push icons. `logo/README.md` says what each one is for |

The screens the demo needs (`docs/PLAN.md`): sign in, sign up, link a child, home (each child's day), a child's day (all taps), the notification feed, and the push permission ask. Plus the app icon and splash screen, if the design has its own.
